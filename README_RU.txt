ORBIT LITE UPDATE (experimental)

В архиве две части:
- server/: Python-сервер + static/index.html (веб-интерфейс)
- android/: Android WebView wrapper

Изменения сервера:
- новые таблицы создаются автоматически при запуске, существующая orbit.db не удаляется;
- добавлены создание групп и каналов, сообщения в сообществах;
- приглашение участников в группу по ID (для канала пока только владелец может писать);
- действия с личным чатом: скрыть чат у себя, закрепить/открепить, блокировать/разблокировать;
- частота фонового обновления снижена, DOM элементы сообщений/чатов сохраняются;
- отправка нескольких выбранных файлов поддерживается последовательной отправкой.

Android:
- WebChromeClient onShowFileChooser добавлен, поддерживает выбор нескольких файлов;
- Android notification bridge добавлен для уведомлений, пока приложение/страница активны.

ВАЖНО:
- Не удаляйте orbit.db и не заменяйте её пустой базой.
- Перед установкой сделайте резервную копию папки сервера.
- Уведомления через опрос работают только пока веб-приложение активно; это не push в фоне/при закрытом приложении.
- Android APK в этом архиве не собран. Исходник MainActivity изменён, но сборка Android SDK/Gradle здесь не запускалась.
- Создание групп/каналов базовое: без полноценных ролей/редактирования/публичного поиска сообществ.
